# Publishing Checklist

## Before publish
- [ ] Kiểm tra 9:16 / 16:9 đúng format
- [ ] Kiểm tra text on screen không quá nhiều
- [ ] Kiểm tra logo DAVIDLE SYSTEM xuất hiện rõ
- [ ] Kiểm tra âm thanh rõ và mượt
- [ ] Kiểm tra bộ nhận diện DAVI nhất quán
- [ ] Kiểm tra CTA rõ ràng

## Platforms
### TikTok
- Resolution: 1080 x 1920
- Format: 9:16

### YouTube
- Resolution: 1920 x 1080
- Format: 16:9

### YouTube Shorts
- Resolution: 1080 x 1920
- Format: 9:16

### Facebook
- Reels: 9:16
- Image post: 4:5 hoặc 1:1
